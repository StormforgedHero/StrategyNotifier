How it works

This static page reads dist/gem/profiles.json generated by the CLI batch run and loads each profile's signals.json as listed in the manifest. Your selection is remembered via the URL and local storage.

  • Manifest: dist/gem/profiles.json (served from repo root).
  • Signals: resolved from each manifest entry.
  • Mobile-first: latest signal is visible without scrolling; history scrolls horizontally when needed.
