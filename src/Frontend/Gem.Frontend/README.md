# GEM frontend

Static, mobile-first viewer for GEM signals with profile switching.

- Live: serve repo root (`python -m http.server 8000`), open `http://localhost:8000/`.
- Demo: from this folder `python -m http.server 8000`, open `http://localhost:8000/` (do not append this path).

Canonical docs: see [Frontend](../../../docs/Frontend.md).
